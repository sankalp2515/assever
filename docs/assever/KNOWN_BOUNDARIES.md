# Supported release boundaries

The owned provider commits commerce, payment and minimum disclosure atomically. Real separate payment and merchant systems require a qualified adapter contract and additional joint-state recovery. The provided mock's closure, fences and one-hour dedupe contract are authored and documented, not inferred from a bank or UPI network.

The catalog has two suppliers and exact rice/oil pack equivalents. No natural-language model can approve new SKUs, infer pack equivalence or broaden disclosure. The draft is a constrained profile requiring full structured human review; arbitrary prose is not a general intent compiler. No customer export consequence exists in the allowed egress schema.

Unknown operations retain exposure, including when only an independent evaluator can see an opaque provider's actual capture. This can stop useful replanning. The product exposes the distinction between independently observed completion and runtime-established completion. A captured order whose runtime state is unknown is not counted twice.

The checker is independent of runtime predicates but trusts source capture. A malicious trusted operator could replace an entire recomputed hash chain and source export. No KMS signature, external attestation, general AP2 certification or P3P UAT claim is made. The optional AP2 test module supports only the exact offline projection described in AP2_PROFILE.md.

Current process crash checks cover durable database state, worker send boundaries, idempotent terminal settlement and eight-process admission. They do not prove arbitrary distributed failure tolerance. PostgreSQL is one local instance. Performance measurements identify actual host/load and target gaps rather than an uptime or latency SLA.

The local self-service session scheme creates isolated synthetic visitors. It is not enterprise identity onboarding. Local HTTP, sample service keys, in-process rate limiting and the optional model-server loopback port require deployment hardening before a shared public environment. Deployment is excluded from this task.

The UI offers a Hindi rendering of the canonical structured view, with restricted translated labels and shared amounts/units. No broad Hindi natural-language understanding or external native-speaker review is asserted. Three-fresh-reader name testing and individual publication permission are owner-dependent tasks; none is fabricated.
