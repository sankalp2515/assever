# Optional AP2 projection profile

This implements an **offline, fully disclosed open-payment constraint projection**, not interoperable AP2 checkout/payment execution. Source: [AP2 v0.2 specification](https://github.com/google-agentic-commerce/AP2/blob/main/docs/ap2/specification.md) and [payment mandate](https://github.com/google-agentic-commerce/AP2/blob/main/docs/ap2/payment_mandate.md), consulted 31 October 2026. The exact snapshot/document hashes belong in the release evidence. No AP2 certification is claimed.

`ap2_projection.project` verifies a synthetic issuer's ES256 signature, an explicitly registered fixture key ID, exact `mandate.payment.open.1`, time window and an expected agent JWK binding. It projects only INR `payment.amount_range` with minimum zero and `payment.allowed_payees` into a narrower native scope preview. Money has exact paise precision. Missing constraints, future schema versions, wrong keys, unknown payees, unresolved disclosures and unsupported constraint types fail closed. The fixture envelope uses the specification example's `delegate_payload`, `_sd_alg` and protected header type. It is not a general SD-JWT/delegation verifier.

The caller supplies trusted issuer/public-key and payee registry entries; token-provided URLs are never fetched for key discovery. The preview cannot activate or dispatch a purchase. Trusted native demand and a new human review remain necessary. Checkout JWT binding, presentation nonce/audience, disclosure reconstruction, delegation-chain verification, credential provisioning and network receipts are outside this offline subset. P3P UAT is separately excluded until an authorized account is available.

Install `services/assever/requirements-ap2.txt` in the test environment and run `pytest services/assever/tests/test_ap2_projection.py`. Fixtures generate ephemeral synthetic P-256 keys and test signature, amount precision, currency, payee identity, schema/time/agent mismatch and unsupported constraints. No private fixture key is published or reused for the runtime issuer.
