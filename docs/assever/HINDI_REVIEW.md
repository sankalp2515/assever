# Hindi structured-field review

The toggle renders the same server-owned purchase values using reviewed English/Hindi label pairs. It does not translate arbitrary purchase prose, alter permission, change SKU IDs, convert currency or infer product equivalence. Navigation and research details remain English.

| English field | Hindi rendering |
|---|---|
| Approved purchase | स्वीकृत खरीद |
| Current obligations | वर्तमान दायित्व |
| Actual outcome | वास्तविक परिणाम |
| All-in gross cap | कुल बजट सीमा |
| Suppliers | स्वीकृत आपूर्तिकर्ता |
| Equivalent SKUs | स्वीकृत वैकल्पिक उत्पाद |
| Purchase count | आदेशों की अधिकतम संख्या |
| Delivery | डिलीवरी स्थान |
| Data shared | साझा की जाने वाली जानकारी |
| Expires | अनुमति की अंतिम तिथि |
| Reserved | आरक्षित राशि |
| Unknown | परिणाम अज्ञात |
| Available budget | उपलब्ध बजट |

Review checked the meaning of budget, reservation, uncertainty, supplier permission and expiry against the English fields. Rice and oil use चावल and तेल. Canonical grams/millilitres remain numerically identical, with ग्राम and मिलीलीटर labels. INR formatting and Latin SKU/delivery identifiers remain unchanged for traceability. This is an implementation language review with browser checks, not a claim of native-speaker user testing or broad Hindi intent understanding.
